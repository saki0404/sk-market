# 蛇口市场 · 市场大屏

2026-10-18 重做版，采用用户选定的“薄荷迎宾”视觉。面向整个市场的到访者：商户目录、店铺详情、市场地图和食材图鉴。WorkBuddy 猫形伙伴与页面边框相融合。

## 运行

Node 22.12+。依赖已锁定；首次使用 `npm ci`。

- `npm run dev`：本机 `http://127.0.0.1:5188/`，默认代理后端 `http://127.0.0.1:18088`。
- 开发模式显式访问 `/?preview=design` 可查看设计示意。顶部常驻标识；示意资料不会请求后端或写入真实快照缓存。
- `npm run check`、`npm test`、`npm run build`、`npm run test:build`：语法、数据契约、构建和生产隔离检查。
- `npm run preview`：预览生产构建；此时 `?preview=design` 无效，生成照片和示意商户不会打包。
- 需要其他端口时直接运行 `node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5190 --strictPort`。

采用 Vite + 原生模块化 JavaScript/CSS，布局与交互已重做。`assets/js/market-data.js` 负责公开数据和离线快照；`assets/js/app.js` 负责页面；`assets/css/market.css` 是新版样式。历史 CSS 暂留作参考，不被新版加载。

## 屏幕比例

现场屏幕已确认为宽1.97米、高2米（约0.985:1，竖向），实际像素分辨率尚未提供。接近正方形的视口采用专用布局：顶部标题和Buddy、中部三张商户卡片、下方并排双入口、底部五列图标与文字。目录采用两列，详情与地图上下排布，长内容在区域内部滚动。

开发服务可打开 `/preview-square.html` 查看可交互的等比例预览。预览内部985×1000只用于模拟比例（对应宽1.97米×高2米），不代表实际屏幕分辨率；该辅助页不进入生产构建。现场应以屏幕原生分辨率全屏打开正式首页，布局按视口比例自动匹配。

## 数据来源与边界

微信小程序上传真实门店照片/介绍 → 管理处审核 → 选择公开分类和名单 → 明确发布 → 市场大屏读取 `GET /api/public/markets/{marketId}/entrance`。

保存草稿、审核通过不等于发布。前端不登录管理账号，不读取私有商户资料，不使用档口小屏设备 manifest 或 APPLIED 回执。没有发布时显示空态；缺图、缺英文、缺地图均如实说明，不制造商户、库存、价格、营业状态或位置。

`config.js` 只允许公开的 `apiBase` 和 `marketId`，不得写入凭据。默认市场 `mkt_001`。开发/生产预览代理可用环境变量 `MARKET_API_PROXY` 指向其他本机测试后端，不改变生产 `config.js`。

## 交互

- 首页最多三个固定品类展示位（按已发布分类顺序）。每3秒，各位置切换该品类下的下一家商户照片、名称、介绍和详情链接；品类与位置不交换。只有一家商户的品类保持原内容。无切换按钮或进度圆点，支持悬停/聚焦暂停、离开首页停播、返回续播和减少动态效果偏好。
- 分类筛选、按店名/编号/介绍/经营品类搜索、商户详情、两张真实门店照片与缺图状态。
- 地图包含用户提供的一层参考图，以及后端明确发布的楼层布局。参考图支持放大缩小、拖动、双指缩放、展开、复位、西侧附区和完整图纸；22类图例及楼梯/无障碍通道可搜索，部分品类有粗略区域高亮和多处定位。参考图不代表实时经营信息，不自动匹配商户或生成导航路线。
- 已发布布局严格使用快照坐标，按店名、编号、品类搜索区域；仅同时匹配 `floorId` 和 `zoneId` 的已发布商户显示在区域内，地图与商户详情可双向跳转。参考图与发布坐标使用独立页签，避免坐标系混用。
- 已发布图鉴存在时显示图鉴入口。
- 两分钟无操作返回首页。横屏、竖屏和窄屏自适应，按钮支持键盘焦点和触摸。

## 同步与离线

约60秒更新公开快照，图片下载后校验 SHA-256 和解码，整份成功后才替换；URL续签和服务器时间变化不会重绘。读取失败保留先前有效快照。IndexedDB保存快照与Blob；生产 Service Worker 预缓存构建产物，支持成功联网后断网整页重载。首次无缓存不能离线恢复，离线时可能仍显示旧资料，页面会标明缓存状态。

上线需 HTTPS 或 localhost；将 `dist/` 托管并配置 `/api` 反代。跨域时另配后端 CORS 和公开签名图片域名。GitHub Pages仅托管静态文件，必须配置可访问的HTTPS后端；推代码不等于现场部署完成。
